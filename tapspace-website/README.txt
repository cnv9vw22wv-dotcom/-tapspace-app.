TAPSPACE WEBSITE — FREE HOSTING INSTRUCTIONS

This folder contains a complete static website:
- index.html (landing page)
- privacy.html (Privacy Policy URL for App Store Connect)
- support.html (Support URL for App Store Connect)
- terms.html (Terms of Use)
- styles.css
- assets/

BEFORE PUBLISHING
1. Replace every instance of support@tapspace.app with an email account you actively monitor.
2. Review the Privacy Policy so it exactly matches the data and third-party services used by the final app.
3. Update the copyright owner if you want your personal or company legal name displayed.

FREE HOSTING — GITHUB PAGES
1. Create a free GitHub account.
2. Create a new public repository named tapspace-site.
3. Upload every file and the assets folder from this package.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /root, then Save.
7. GitHub will provide a live URL such as:
   https://YOUR-USERNAME.github.io/tapspace-site/

APP STORE CONNECT URLS
Privacy Policy URL:
https://YOUR-USERNAME.github.io/tapspace-site/privacy.html
